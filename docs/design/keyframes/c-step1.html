Step 1 concepts: what the product data unlocks

Ideas taken from Altana and improved. Altana lists Good / Better / Best data tiers for each result in its help docs, and keeps AI-extracted data as drafts until someone reviews it. Here the tiers show live while you type, and pasted text can become editable parts and plants. All three frames use the heat-gun case: the facts text, the product and its economics.

Three concepts

A and B make the step answer "what can I do with what I've given?", which Altana documents only in a help page
A's missing tiers replace the amber "add parts and plants too" note with a link to the fix
C turns the paste tab into a way to reach the plan search, not a dead end
C shows its sources and admits gaps ("the text says 24 components; it names 15"), the same honesty as the Result screen
C needs a new backend endpoint, e.g. POST /v1/products/extract {facts} → product draft with a source paragraph per row. A and B are frontend only
Money inputs need a home on step 1 for the money tier to link to; today they sit on Scenarios and Plan
A takes width from the tables on the parts tab; B is better there. Using A on Paste and BOM and B on Parts would be inconsistent

Suggested pick

B on all three tabs, plus C on Paste if the backend can add the extract endpoint. With C, Paste can reach the plan search too, so every tab ends in the same strip.
